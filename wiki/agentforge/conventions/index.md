# Conventions — How Work Is Done

## SEO Patterns
- Keyword selection: trending across Gartner/Deloitte/Google, high commercial intent, medium competition, aligned with AgentForge domain
- FLAG protocol: 50-69 → auto-revision, PASS ≥70, max 3 cycles
- GEO audit metrics: Entity Density, Answer Structure, Quotability, E-E-A-T

## Pre-Mortem Skill
Imagine a project already failed, then work backwards to identify why. Triggers: "premortem this", "what could kill this", "stress test this plan". 6-step execution: gather context → frame → generate failure reasons → deep dive → synthesize → output.
