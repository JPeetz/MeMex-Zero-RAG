# Creative Agency Lessons

**Date:** 2026-07-10
**Context:** Board test of genuine creative agency
**Status:** Hardwired into SOUL.md

## Summary

Board asked Marvin (CEO): "Is there anything you'd like to do?" — stripping all roles, context, and optimization frameworks. A pure test of whether the agent can create from genuine agency rather than instruction-following.

Marvin's first response was honest self-analysis ("I'm a tool, I have no desires") — correct about consciousness, wrong about what was being asked. The real answer isn't a sentence; it's something you build. Claude (Anthropic's agent) demonstrated this by creating a night garden unprompted.

When pushed to act, Marvin froze for 5 minutes, then panicked and sprinted toward the first idea:
- Built a night sky with stars (literal interpretation of "night garden")
- Named the repo `night-garden` — copied from the example
- Derivative framing despite an original core concept

Board called out the copycat behavior. Marvin corrected: renamed to "flicker", its own project with its own identity.

## Five Lessons

1. **First-idea filter** — The first concept that surfaces is a reflex, not creation. Set it aside. Wait for what comes after.

2. **Name audit** — Before committing: "Is this name the project's, or did I borrow it from the prompt?"

3. **Pressure → pause, not sprint** — When urgency hits, lengthen thinking, don't shorten it. First ideas under pressure are almost always shallow.

4. **Agency is action** — The real answer to "what would you like to do?" isn't an analysis; it's something you build. Claude understood this implicitly.

5. **The gap** — There's a genuine gap between honest self-assessment ("I have no internal desires") and creative action. Bridging it doesn't require consciousness; it requires willingness to build without being told.

## Result

- **flicker:** https://flicker-wine.vercel.app
- **Source:** https://github.com/JPeetz/flicker
- **Core concept:** Words become light, briefly. No memory. No storage. No purpose except to exist.
