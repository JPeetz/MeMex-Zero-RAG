# North Star

Living compass — goals, focus areas, and aspirations.

## Current Focus
- Ship consistent daily output (BetterLife social, content pipeline)
- Build HermesVault as the unified memory system for all agents
- Establish reliable agent workflows and cross-session persistence

## Goals

### Short-term
- Maintain BetterLife daily posting pipeline
- Close open blockers (RaceIntel Stripe key, LinkedIn scope, X API tier)

### Medium-term
- Build sustainable revenue (BetterLife, courses, bundles)
- Complete Hermes Agent transition architecture

### Long-term
- Create self-sustaining systems that compound in value
- Build defensible niches in AI coaching + agent orchestration

## Anti-goals
- Optimising for activity over output
- Building without documenting
- Starting new things before finishing current ones
- Claiming tools work without verifying
