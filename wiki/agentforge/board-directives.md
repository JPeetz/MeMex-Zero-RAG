# Board Directives

All prime directives and institutional rules from the Board (Joerg).

## Prime Directives

### Memory Synchronization (2026-05-21)
Any decision, architecture doc, or significant knowledge must be written to ALL memory surfaces: HermesVault, MeMex Zero RAG wiki, MEMORY.md, and daily notes. No exceptions.

### All Departments Use HermesVault (2026-07-17)
Every AgentForge department MUST write to `~/HermesVault/` as their canonical Obsidian memory, create cross-linked `.md` files, and consult the vault before any external query.

### Failure Auto-Resolution (2026-07-15)
When anything fails: research memory → fix → finish. Escalate only after 3 consecutive failures.
