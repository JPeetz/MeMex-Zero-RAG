# Learning Loop — Agent Reflections & Closed Learning

Closed learning loop: Act → Reflect → Extract → Carry Forward.

## Components
1. **Post-task reflection** — every agent reflects after tasks
2. **Cross-session pattern extraction** — heartbeats identify recurring patterns
3. **User model building** — continuous update of Joerg's preferences
4. **Self-improving skills** — update SKILL.md when patterns emerge
5. **Daily memory consolidation** — prune, identify contradictions

## How to Use
1. After any significant task: write a reflection
2. Pattern found? Add to [[lessons-learned]]
3. User preference discovered? Update joerg-profile
4. Decision made? Add to [[decisions]]
5. Protocol improvement? Update [[board-directives]]
