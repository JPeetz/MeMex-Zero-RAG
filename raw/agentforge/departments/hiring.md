## Standards (5-Level Benchmark)

Developed 2026-05-24 from `ai-agents-from-scratch` repo integration:

| Level | Focus |
|-------|-------|
| 1. Fundamentals | Basic agent loop, tool use |
| 2. Tool Architecture | Complex tool chains, error handling |
| 3. Agent Loop | Multi-turn, memory, state management |
| 4. Production Readiness | Error recovery, logging, monitoring |
| 5. Local-First | On-device inference, privacy |

## Process

1. **Proposal** — Department need identified, agent spec drafted
2. **Route to hiring agent** — never design agents yourself (CEO protocol)
3. **Adversarial review** — mandatory before any deploy
4. **Register** — in MeMex agents/ registry + SecondBrain
