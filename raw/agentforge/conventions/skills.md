# Skills — Vault Workflows & Slash Commands

> Custom slash commands, subagents, and reusable workflows.
> **Related:** [[Board-Directives]], [[Departments]]

---

## Daily Workflow

| Command | Purpose |
|---------|---------|
| `om-standup` | Morning kickoff — load context, review yesterday, surface tasks |
| `om-dump` | Freeform capture — dump anything, routed to right notes |
| `om-wrap-up` | Full session review — verify notes, indexes, links |

## Editing & Synthesis

| Command | Purpose |
|---------|---------|
| `om-humanize` | Voice-calibrated editing — makes drafted text sound like you |
| `om-weekly` | Weekly synthesis — cross-session patterns, North Star alignment |

## Meeting Prep & Capture

| Command | Purpose |
|---------|---------|
| `om-prep-1on1` | Prep for upcoming 1:1 — person context, open items, agenda |
| `om-capture-1on1` | Capture 1:1 transcript into structured vault note |
| `om-incident-capture` | Capture incident from Slack into structured note |
| `om-slack-scan` | Deep scan Slack channels for evidence |
| `om-meeting` | Prep for meeting by topic |
| `om-intake` | Process meeting notes inbox |

## Go Development

| Command | Purpose |
|---------|---------|
| `om-go-review` | Code review checklist — Go-specific review order |
| `om-go-bench` | Run benchmarks, profile output |
| `om-go-test` | Run tests with race detection |

## Vault Management

| Command | Purpose |
|---------|---------|
| `om-archive` | Archive completed work notes |
| `om-staleness` | Check for stale entries (>30 days) |
| `om-link` | Find unlinked notes and add connections |
